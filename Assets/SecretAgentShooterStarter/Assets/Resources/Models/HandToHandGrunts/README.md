# Hand-to-Hand Grunt Models

The nine `HandToHandGrunt_*.glb` files in this folder are the Artcraft models supplied by the project owner.

- `PrototypeSceneBuilder` selects one model from this pool for the hand-to-hand grunt.
- Set `Hand To Hand Grunt Variant` to `-1` for a random model or `0` through `8` for a fixed model.
- The models are static, high-detail meshes. They use the prototype capsule hitbox and whole-object knockout/carry poses until optimized and rigged.
- Confirm the source license permits use and redistribution before shipping the game.
